
# ☢️ Radioaktiv

## 🎮 Sobre o Jogo
**Radioaktiv** é um **survival horror em terceira pessoa** com foco em terror psicológico e atmosfera opressiva.  
Você joga como **██████**, um ex-assistente de laboratório que, após a explosão nuclear de uma usina, precisa sobreviver nos corredores escuros e claustrofóbicos da instalação devastada, enfrentando antigos colegas que se transformaram em criaturas deformadas e hostis.

O jogo aposta em ambientes apertados, tensão constante e ausência de refúgio, criando uma experiência desconfortável, intensa e assustadora.

---

## 🕹️ Mecânicas Principais
- **Movimentação livre** em terceira pessoa  
- **Ambientes claustrofóbicos** com iluminação limitada  
- **Sistema de combate**: mirar e atirar  
- **Exploração de itens**: coleta de munição, chaves e documentos  
- **Interação com portas, máquinas e registros**  
- **Inimigos grotescos** e únicos, baseados em antigos cientistas  

---

## 🗺️ Estrutura Inicial
- ✅ **Nível 1**: exploração inicial e combate contra o primeiro híbrido grotesco.

## 🖥️ Plataforma
- Desenvolvido em **Unity**  
- Plataforma alvo: **Windows PC**  
- Estilo gráfico: **Low-Poly sombrio e estilizado**

---

## 🛠️ Como Executar
1. Baixe ou clone este repositório:
   ```bash
   git clone https://github.com/seuusuario/radioaktiv.git
   ```
2. Abra o projeto pelo **Unity Hub** (versão recomendada: `2022.3 LTS`)
3. Abra a cena `MainMap`
4. Compile para **Windows** em `File > Build Settings`
